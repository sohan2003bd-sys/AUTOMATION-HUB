# বাংলা Shorts বট — প্রফেশনাল সংস্করণ (গবেষণা → স্ক্রিপ্ট → ফ্যাক্ট-চেক → ভয়েস → আসল ফুটেজ → ভিডিও → ইউটিউব)

নিশ: **প্রযুক্তি ও AI টিপস**, ভাষা: **বাংলা**, ১০টি ক্যাটাগরি (`config.yaml`)।
এই ধাপে ভিডিও তৈরি হয় `output/` ফোল্ডারে (`.mp4` + আপলোডের জন্য `.json`)। ইউটিউবে আপলোড ও শিডিউল ধাপ ২-এ।

## সেটআপ
1. Python 3.10+ ও FFmpeg ইনস্টল করুন।
2. `pip install -r requirements.txt`
3. **বাংলা ফন্ট** (খুব জরুরি, নইলে অক্ষর ভেঙে যায়):
   - Ubuntu/GitHub Actions: `sudo apt-get install -y ffmpeg fonts-noto-core libraqm0 libfribidi0`
   - Windows/Mac: Google Fonts থেকে *Noto Sans Bengali* (Bold) নামিয়ে `assets/fonts/` ফোল্ডারে রাখুন (ফোল্ডার বানিয়ে নিন)।
4. AI কী সেট করুন (একটা): `ANTHROPIC_API_KEY` অথবা `GEMINI_API_KEY`, আর `config.yaml`-এ `llm.provider` মিলিয়ে নিন।
   Gemini-র একাধিক কী দিতে পারেন: `GEMINI_API_KEY`, `GEMINI_API_KEY_2`, `_3`, `_4`, `_5` — একটার কোটা শেষ হলে বট নিজে পরেরটায় যায়, শেষেরটার পর আবার প্রথমটায় ফেরে। (ভালো ফল পেতে প্রতিটি কী আলাদা গুগল অ্যাকাউন্ট/প্রজেক্ট থেকে বানান — একই প্রজেক্টের কী-গুলোর কোটা একসাথে শেষ হয়।)
   মডেলের নাম `config.yaml`-এ আছে; না চললে আপনার অ্যাকাউন্টে থাকা নামটি বসান।
   (ভয়েস শুধু Microsoft Edge-এর বিনামূল্যের বাংলা কণ্ঠে — `tts.voice`-এ নারী/পুরুষ কণ্ঠ বদলানো যায়।)
5. `config.yaml`-এ `channel.handle` নিজের চ্যানেলের নাম দিন।

## চালানো
```
python -m shorts demo --tts edge      # নমুনা ভিডিও, বাংলা ভয়েসসহ (AI কী লাগে না)
python -m shorts ideas --per-category 20
python -m shorts make --count 3       # ৩টি ভিডিও বানাবে (ক্যাটাগরি ঘুরিয়ে ঘুরিয়ে)
python -m shorts status
```
`--tts silent` দিলে ভয়েস ছাড়া দ্রুত পরীক্ষা হয়।

## গুরুত্বপূর্ণ
- প্রথমে `demo`, তারপর ৩–৫টি ভিডিও বানিয়ে **নিজে দেখুন**: তথ্য ঠিক আছে কিনা, উচ্চারণ ঠিক আছে কিনা।
  AI ভুল ধাপ লিখতে পারে; আপলোডের আগে অন্তত শুরুতে নিজে যাচাই করুন।
- ভিডিওগুলো একই ছাঁচের হলে ইউটিউব মনিটাইজেশন কেটে দিতে পারে (inauthentic content নীতি)।
  তাই শুরুতে কম সংখ্যায় (দিনে ৫–১০টি) চালান।
- একটা ভিডিও রেন্ডারে প্রায় আধা মিনিট লাগে (`video.motion: none` দিলে দ্রুত হয়)।

## ফাইল
- `shorts/ideas.py` আইডিয়া, `scriptgen.py` স্ক্রিপ্ট, `tts.py` ভয়েস, `render.py` ভিডিও, `store.py` কাজের তালিকা (`data/queue.jsonl`)।
- `shorts/youtube.py` ইউটিউব আপলোড, `shorts/runner.py` প্রতিদিনের কাজ, `.github/workflows/shorts.yml` প্রতিদিন নিজে চালানো।

## ধাপ ২ — ইউটিউব আপলোড ও প্রতিদিন নিজে চলা
**GitHub Secrets (repo → Settings → Secrets and variables → Actions):**
`YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`, এবং AI কী: `ANTHROPIC_API_KEY` অথবা `GEMINI_API_KEY` (config.yaml-এর `llm.provider` মিলিয়ে)।

**চালানো:** repo → Actions → *shorts-daily* → Run workflow। শুরুতে `count = 1`, `privacy = private` দিয়ে পরীক্ষা করুন।
প্রতিদিন সকাল ৮টায় (বাংলাদেশ) নিজে চলে, ২টি ভিডিও বানায় (মাসে ~৬০টি; `limits.monthly_max` দিয়ে সীমা বাঁধা)।

**`config.yaml` → `upload.privacy`:**
- `private` — আপলোড হয়, শুধু আপনি দেখেন (শুরুতে নিরাপদ)।
- `public` — সঙ্গে সঙ্গে প্রকাশ।
- `schedule` — `slots`-এর সময়ে ছড়িয়ে প্রকাশ (প্রথম সময় আজ বাকি থাকলে আজ, নইলে কাল)।

**সতর্কতা:** নতুন API প্রজেক্টের আপলোড Google প্রথমে Private করে রাখে; Public করতে অডিট লাগে।
এমন হলে লগে ⚠ দেখাবে। আপলোড সীমা/কোটা শেষ হলে বট থামে, ভিডিওটি পরের দিন আবার চেষ্টা হয়।
`data/queue.jsonl` প্রতিবার রিপোতে সেভ হয়, তাই একই ভিডিও দুবার আপলোড হয় না।

## ধাপ ৩ — প্রফেশনাল আপগ্রেড (নতুন)

| ফিচার | কী করে | কী লাগে |
|---|---|---|
| **গবেষণা + ফ্যাক্ট-চেক** | স্ক্রিপ্টের আগে গুগল সার্চে তথ্য যাচাই; ভুল/পুরনো বিষয় বাতিল (নতুন আইডিয়া নেয়); স্ক্রিপ্ট লেখার পর প্রতিটি দাবি আবার মেলানো; বিবরণে তথ্যসূত্র | `llm.provider: gemini`, `GEMINI_API_KEY` |
| **আসল ফুটেজ/ছবি** | প্রতিটি দৃশ্যের কথা অনুযায়ী Pexels/Pixabay/Unsplash (ছবি) থেকে লম্বালম্বি ফুটেজ; একই ক্লিপ বারবার আসে না | `PEXELS_API_KEY`, `PIXABAY_API_KEY`, `UNSPLASH_ACCESS_KEY` — যেকোনো একটা (ফ্রি) |
| **ভয়েস** | Edge বাংলা কণ্ঠ; ভয়েস পরিষ্কার + ভলিউম সমান | কোনো কী লাগে না |
| **প্রিমিয়াম ডিজাইন/অ্যানিমেশন** | ফুটেজের ওপর ছায়া, অ্যানিমেটেড হেডলাইন, রঙিন হাইলাইট শব্দ, কথার সঙ্গে ক্যাপশন, ১০ রকম ট্রানজিশন | — |
| **অডিও** | ব্যাকগ্রাউন্ড মিউজিক (ভয়েসের সময় নিজে নিচু), হালকা ট্রানজিশন-সাউন্ড, YouTube-মানের লাউডনেস (-১৪ LUFS) | মিউজিক: `assets/music/`-এ কপিরাইট-মুক্ত গান |
| **হাই কোয়ালিটি** | `video.quality: high` = ১০৮০×১৯২০ (CRF 17); `ultra` = ১৪৪০×২৫৬০ | — |
| **নিজের ভিডিও স্মার্ট এডিট** | নীরবতা কাটা, ৯:১৬ রিফ্রেম, বাংলা ক্যাপশন, ভয়েস মাস্টারিং, টাইটেল/বিবরণ | ক্যাপশনে Gemini |

### নতুন GitHub Secrets (ঐচ্ছিক, না দিলে ওই অংশ বাদ যায়, ভিডিও আটকায় না)
`PEXELS_API_KEY` (pexels.com/api), `PIXABAY_API_KEY` (pixabay.com/api/docs), `UNSPLASH_ACCESS_KEY` (unsplash.com/developers — Access Key)। কিছু না মিললে শেষ ভরসা Lorem Picsum (কী লাগে না) চালাতে `media.picsum_fallback: true` দিন — তবে ছবি কিওয়ার্ডের সঙ্গে মেলে না।

### প্রথমে যা করবেন
1. `python -m shorts doctor` — কী কী বসানো আছে/নেই দেখাবে (Actions-এও রানের শুরুতে চলে)।
2. `config.yaml`-এ `channel.handle` বসান; ইচ্ছা হলে `assets/music/`-এ গান রাখুন।
3. Actions → *shorts-daily* → Run workflow → `count = 1`, `privacy = private`; ভিডিও নিজে দেখে নিন।

### নিজের ভিডিও এডিট
- কম্পিউটার/Termux-এ: `python -m shorts edit আমার_ভিডিও.mp4` (ফোল্ডারও দেওয়া যায়) → `output/edit-*.mp4`।
- শুধু ফোনে: ভিডিও `inbox/` ফোল্ডারে পুশ করুন (প্রতিটি ফাইল ১০০ এমবির নিচে) → Actions → *edit-my-video* → Run workflow → শেষে Artifacts থেকে নামিয়ে নিন (বা `upload` টিক দিয়ে সরাসরি আপলোড)।
- ক্যাপশনের সময় Gemini অডিও শুনে আন্দাজ করে; আপলোডের আগে দেখে নিন।

### সতর্কতা
- গুগল-সার্চ গবেষণার ফ্রি সীমা কম। সীমা শেষ হলে গবেষণা বাদ যায় (লগে ⚠ দেখাবে)। নিয়মিত ১০টি ভিডিওর জন্য Gemini-তে বিলিং চালু করা ভালো।
- রেন্ডার আগের চেয়ে ধীর (১০৮০p-তে ২–৪ মিনিট/ভিডিও); ১০টির রান ~৩০–৪০ মিনিট। `ultra` আরও ধীর।
- ফ্যাক্ট-চেক ভুল কমায়, শূন্য করে না — শুরুতে কিছু ভিডিও নিজে যাচাই করুন। একই ছাঁচের ভিডিও ইউটিউবের "inauthentic content" নীতিতে পড়তে পারে; ফুটেজ ও হুক বৈচিত্র্য এতে সাহায্য করে, কিন্তু নিশ্চয়তা নয়।
- ফুটেজ/ছবি Pexels/Pixabay/Unsplash লাইসেন্সে বাণিজ্যিক ব্যবহারযোগ্য; ক্রেডিট `output/*.json`-এর `credits`-এ থাকে। মিউজিকের লাইসেন্স আপনি নিজে দেখবেন।
